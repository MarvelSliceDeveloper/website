# Internationalization (i18n)

## Status

i18n scaffolding is in place but **not yet wired into the UI**. This document describes the setup and how to activate it.

## Current Setup

- **Library**: `next-intl` (configured in `pnpm-workspace.yaml` but not imported in app)
- **Locale files**: `/apps/web/messages/en.json`
- **Middleware**: `apps/web/src/middleware.ts` already handles locale detection (optional)

## How to Activate

1. Set `FEATURE_I18N=true` in your `.env` (feature flags enabled)
2. Wrap the root layout with `NextIntlClientProvider`
3. Add locale switcher component
4. Add additional locale files (`fr.json`, `es.json`, etc.)

## Translation Files

Format:

```json
{
  "common": {
    "login": "Log In",
    "signup": "Sign Up",
    "logout": "Log Out"
  },
  "nav": {
    "dashboard": "Dashboard",
    "courses": "Courses",
    "settings": "Settings"
  }
}
```

## Adding a New Locale

1. Copy `en.json` → `fr.json`
2. Translate values
3. Add locale to `next.config.ts` `i18n.locales` array
4. Update middleware locale detection
